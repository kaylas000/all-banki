## Типы карточек

### 1. Горизонтальная (credit-card)
- **Категории:** Кредиты, Карты, Вклады, Ипотека, Инвестиции, РКО
- **Структура:** Лого → Название → Параметры в строку → Кнопки
- **Особенности:** Скрытые детали при наведении

### 2. Вертикальная — займы (offer-card + offer-params-col)
- **Категория:** Займы
- **Структура:** Лого → Название → Параметры (ставка, срок, сумма, одобрение)
- **Кнопки:** «Получить деньги →», «Подробнее»

### 3. Вертикальная — страхование (offer-card + offer-card-rate)
- **Категория:** Страхование
- **Структура:** Лого → Название → Описание → Цена → Покрытие → Теги
- **Кнопки:** «Подробнее», «Рассчитать»

## Генерация страниц

### Процесс:
1. Данные хранятся в `assets/data/*.json` (152 оффера)
2. Шаблоны в `assets/templates/` (7 шаблонов)
3. `generate.py` читает JSON + шаблоны → генерирует HTML
4. Компоненты (header, footer) вставляются инлайново

### Добавление нового оффера:
1. Добавить JSON в `assets/data/credits.json` (или другую категорию)
2. Запустить `python generate.py`
3. Запушить в GitHub
