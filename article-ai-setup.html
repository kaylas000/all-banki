Как установить VS Code, Claude Code и подключить API модели

Автор: Команда Все-Банки· 10 августа 2026·7 мин чтения·Инструменты

Коротко: за 15–20 минут вы установите Visual Studio Code, добавите в него Claude Code, получите API-ключ на шлюзе hubris и подключите модель прямо в терминал. В конце — готовая кнопка для получения API.

Шаг 1. Установка Visual Studio Code

Шаг 1

Visual Studio Code — бесплатный редактор кода от Microsoft. Он работает на Windows, macOS и Linux.

  • Откройте официальный сайт code.visualstudio.com.
  • Нажмите кнопку загрузки — сайт сам определит вашу систему.
  • Запустите установщик и оставьте настройки по умолчанию.
  • После установки откройте VS Code и откройте встроенный терминал: меню Терминал → Новый терминал.

Терминал внутри VS Code — удобное место для работы с Claude Code, потому что весь процесс — код, команды и результат — остаётся в одном окне.

Шаг 2. Установка Claude Code

Шаг 2

Claude Code — официальный инструмент Anthropic для работы с моделями прямо из терминала: от написания кода до анализа файлов.

  • Убедитесь, что установлен Node.js версии 18 или выше — сайт nodejs.org.
  • В терминале VS Code выполните установку: 
    npm install -g @anthropic-ai/claude-code
  • Проверьте установку: 
    claude --version

Если команда не найдена — перезапустите терминал или VS Code. После этого можно запускать claude и подключать API.

Шаг 3. Получение API-ключа на шлюзе hubris

Шаг 3

Шлюз (gateway) — сервис-посредник, который даёт доступ к моделям через единый API-ключ. Это удобно, когда нужно быстро подключить модель без сложной настройки собственного аккаунта.

  • Перейдите по ссылке ниже и зарегистрируйтесь на шлюзе hubris.
  • В личном кабинете найдите раздел API-ключи и создайте новый ключ.
  • Скопируйте ключ — он понадобится на следующем шаге.

Шаг 4. Подключение API в Claude Code

Шаг 4

Claude Code читает API-ключ из переменных окружения. Схема подключения стандартная для прокси-доступа:

  • ANTHROPIC_API_KEY — ваш ключ со шлюза hubris.
  • ANTHROPIC_BASE_URL — адрес API шлюза (точный адрес смотрите в инструкции шлюза после регистрации).

Задайте переменные в терминале перед запуском:

export ANTHROPIC_API_KEY="ваш_ключ"
export ANTHROPIC_BASE_URL="адрес_шлюза"

На Windows (PowerShell) вместо export используется:

$env:ANTHROPIC_API_KEY = "ваш_ключ"
$env:ANTHROPIC_BASE_URL = "адрес_шлюза"

После этого запустите claude — Claude Code проверит подключение и начнёт работу с моделью.

Готово: редактор установлен, Claude Code работает, API подключён. Можете просить модель писать код, разбирать файлы и отвечать на вопросы прямо в терминале VS Code.
